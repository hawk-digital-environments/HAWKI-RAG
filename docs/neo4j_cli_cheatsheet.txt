my neo4j terminal notes
=======================

before running anything
-----------------------------------
- the neo4j container is up (`rawki_neo4j` on the hawki network).
- username/password: `neo4j` / `ixdlabPass123` (unless i changed them).
- either i have `cypher-shell` installed locally or i run it through docker.

 cypher-shell
---------------------------
- from my machine:
  ```DD
  cypher-shell -a bolt://localhost:7688 -u neo4j -p ixdlabPass123
  ```
- lazier way (always works):
  ```
  docker exec -it rawki_neo4j cypher-shell -u neo4j -p ixdlabPass123
  ```

quick reminders
---------------
- list databases: `SHOW DATABASES;`
- community edition sticks to the default `neo4j` db, so no fancy switching.

checking what’s in there
------------------------
- count nodes grouped by label:
  ```
  MATCH (n) RETURN labels(n) AS labels, count(*) AS count ORDER BY count DESC;
  ```
- peek at a few entities:
  ```
  MATCH (n:Entity) RETURN n LIMIT 10;
  ```
- count relationships by type:
  ```
  MATCH ()-[r]->() RETURN type(r) AS type, count(*) AS count ORDER BY count DESC;
  ```
- peek at a few relationships:
  ```
  MATCH (a)-[r:REL]->(b) RETURN a, r, b LIMIT 10;
  ```

nuking stuff (careful!)
-----------------------
- wipe the whole graph:
  ```
  MATCH (n) DETACH DELETE n;
  ```
- remove only relationships:
  ```
  MATCH ()-[r]->() DELETE r;
  ```
- drop one label (and anything attached to it):
  ```
  MATCH (n:Entity) DETACH DELETE n;
  ```
- enterprise only: drop the database
  ```
  DROP DATABASE hawki_kd IF EXISTS;
  ```

script it
------------------------
- one-liner wipe:
  ```
  docker exec rawki_neo4j \
    cypher-shell -u neo4j -p ixdlabPass123 "MATCH (n) DETACH DELETE n;"
  ```
- one-liner counts:
  ```
  docker exec rawki_neo4j \
    cypher-shell -u neo4j -p ixdlabPass123 \
    "MATCH (n) RETURN labels(n) AS labels, count(*) AS count ORDER BY count DESC;"
  ```

extra scraps 
-----------------------------------
- `:help` inside cypher-shell reminds me of the basics.
- add `--format plain` if i need CSV-friendly output.
- if deletes get too big, apoc batching saves me:
  ```
  CALL apoc.periodic.iterate(
    'MATCH (n:Entity) RETURN n',
    'DETACH DELETE n',
    {batchSize: 1000}
  );
  ```
  (only works if the APOC plugin is around.)
